## Section 18.8 - Binary trees

A binary tree has at most two children per node.

### Traversal

An in-order traversal visits the left subtree, root, and right subtree.

## Section 18.9 - Binary search trees

In a binary search tree, keys in the left subtree precede the root key and keys
in the right subtree follow it. Search compares the target with each visited key.
